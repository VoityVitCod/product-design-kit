# Проверка комплекта

| Проверка | Что установлено |
| --- | --- |
| Структура | В архиве присутствуют девять профилей TOML, навык, локальный установщик и инструкции. Проверены относительные ссылки, распаковка и метаданные навыка. |
| Обнаружение в Codex | В отдельной рабочей папке Codex загрузил корневой AGENTS.md и включил product-design-workflow в каталог доступных навыков. |
| Установка | В чистой папке команда просмотра вывела план. После применения появились обе скрытые папки с ролями и навыком. Повторная установка сохранила содержимое файлов. |
| Существующий проект | Исходный текст AGENTS.md сохранён, блок подключения добавился один раз. Заполненные стандарты проекта сохранились. При конфликте в одноимённой роли установщик остановился до записи. |
| Пробная работа | Отдельный QA-агент получил инструкцию из файла роли и выявил недостающий критерий при смене даты. [Поручение и результат](PORTFOLIO.md) |
| Независимый просмотр | Пять профилей рецензентов проверены по составу и формату. Такой просмотр запускается отдельно на выбранном материале. |
| Подготовка к распространению | В публичных материалах используется подпись VoityVIT. Проверены имена файлов, состав архива и отсутствие локальных путей, приватных идентификаторов и служебных копий. |

Пробный сценарий проверял качество инструкции по тексту. Результаты прохождения прототипа и испытаний на устройстве фиксируются отдельно для конкретного проекта.
