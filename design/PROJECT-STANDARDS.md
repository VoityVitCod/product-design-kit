# Карточка проекта

Для начала достаточно ссылки на текущий материал и одного предложения о нужном изменении. Заполняй те поля, которые помогают принять решение или повторить проверку. Факты бери из рабочего файла, задачи, одобренного образца и действующей библиотеки.

## Короткий бриф

> На [экран или ссылка] человек хочет [задача]. Измени [конкретный элемент или шаг]. Образец [ссылка или вложение]. Результат нужен в виде [формат].

## Паспорт

| Поле | Запись проекта |
| --- | --- |
| Продукт и действие пользователя | |
| Аудитория, платформа, рабочий размер экрана | |
| Актуальный файл и ссылка на целевой объект | |
| Одобренный экран или состояние для сравнения | |
| Библиотека, стили, переменные, правила именования | |
| Источники текста, данных, фото и оригиналов брендовых материалов | |
| Формат результата и где его открыть | |

## Решения

| Где действует | Правило или наблюдение | Основание | Источник и дата сверки |
| --- | --- | --- | --- |
| | | | |

В графе основания укажи один из трёх вариантов.

- **Подтверждено** — есть прямое требование или одобренный образец. Зафиксируй его область применения.
- **Видно в макете** — найдено конкретное состояние или свойство. При дальнейшем изменении сверяйся с живым узлом.
- **Принято для итерации** — обратимое решение, которое помогает проверить текущую задачу. Укажи причину при наличии содержательного выбора.

## Пример для сервиса бронирования

| Поле | Учебный пример |
| --- | --- |
| Задача | Организатор встречи выбрал переговорную и хочет изменить время перед подтверждением. |
| Вход | Дата и выбранная комната уже видны на экране доступных интервалов. |
| Изменение | По действию «Изменить время» открывается экран интервалов с прежним выбором. |
| Образец | Вложенный в задачу экземпляр строки выбранного интервала. |
| Критерий проверки | Выбрать 14:00, открыть подтверждение и вернуться. Проверить, что отмечено 14:00. Выбрать 15:00, открыть подтверждение и увидеть 15:00. При повторном возврате отмечено 15:00, комната прежняя. |
| Результат | Редактируемые экраны выбора и подтверждения, связанные в прототипе. |
